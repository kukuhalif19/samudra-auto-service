# Samudra Auto Service

Prototype website presentasi untuk Samudra Auto Service, bengkel fisik dan layanan home service di Pekanbaru.

## Jalankan lokal

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.

## Catatan prototype

Nomor telepon/WhatsApp masih menggunakan placeholder `XXXXX`. Tautan Google Maps menggunakan listing resmi yang tersedia. Sebelum produksi, ganti placeholder dan lengkapi alamat, jam operasional, foto bengkel, serta klaim layanan yang sudah dikonfirmasi pemilik.

## Deploy

Project ini disiapkan untuk GitHub + Vercel. Push ke repository yang terhubung ke Vercel akan memicu deployment otomatis.
