# Arsitektur

Prototype memakai Next.js App Router sebagai shell deployment. Homepage memuat `public/prototype.html`, yaitu mockup full-page yang telah disetujui, agar visual presentasi tetap konsisten. Tidak ada backend, database, autentikasi, atau booking otomatis.

Interaksi demo pada form dan toggle home service berjalan di browser. Semua kontak memakai placeholder `XXXXX`. Google Maps memakai tautan listing Samudra yang tersedia.
